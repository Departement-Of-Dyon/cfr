# Code of Federal Regulations — Index

The CFR codifies all general and permanent rules published by federal
agencies in the Federal Register. 50 titles.

## Official sources
- eCFR (current, daily): https://www.ecfr.gov
- Annual CFR bulk XML: https://www.govinfo.gov/bulkdata/CFR
- GovInfo API: https://api.govinfo.gov (free API key)
